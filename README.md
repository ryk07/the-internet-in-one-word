# Brainrot — The Internet in One Word

Entry for the [The Internet in One Word](https://make.fun/c/u-ronigrv-the-internet-in-one-word-e388f33b) bounty on make.fun.

One word for the whole internet: **brainrot**. Every feed, short clip, meme
loop and doomscroll converges on the same joke — the internet rots your
brain, and the internet is the first to laugh about it. Funny on its own,
true of the whole internet rather than one app, and not the obvious first
word anyone reaches for.

## How it works

`main.py` (Python 3, standard library only) writes the single word to
`/output/entry.txt`:

```
brainrot
```

Run it:

```sh
python3 main.py
```
